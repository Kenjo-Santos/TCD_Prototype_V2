How it works

  1. A safety check runs first.
  2. Help and greeting commands are handled locally.
  3. The system checks whether the question relates to the FAQ topic.
  4. The embedding model finds similar FAQ questions.
  5. The Cross-Encoder re-ranks the best candidates.
  6. The chatbot returns a saved answer or an appropriate fallback.
